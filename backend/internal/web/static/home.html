register a server

A casting booth for a match on your own Nitrox server: the dashboard, the overlays and the bracket, behind tokens that are yours. You need no account, because there is none.

A booth lasts 24 hours. When the time is up the booth, its match and everything written into it are deleted, and the tokens stop working. There is no way to extend one and no way to get one back — make another when you need another.

your three tokens

These are shown once. The booth keeps only their hashes, so nobody — including whoever runs this service — can show them to you again. Copy them somewhere before you leave this page: a booth is its tokens, and losing them loses the booth.

Three rather than one, deliberately: watching does not confer writing. The view token is the one that goes in an overlay URL and into a screen share, so it is the one that must not be able to reset your match.

point your server at it

Paste this into lms-tournament.yaml beside your server executable, and set the ingest token in the server's own environment as LMS_INGEST_TOKEN. There is no token: field in the config file and writing one is an error — the file is the one you hand to your players.

watch it

The dashboard link carries the view token so it opens straight into your booth; the page takes it out of the address bar and keeps it in that browser's own storage. Send the plain address to anybody who should paste the token themselves.

the OBS sources

Each is a browser source in OBS: add one, paste the address, size it to the pixels beside its name. Every address says YOUR_VIEW_TOKEN — this page is shown around and read out loud, so it never carries the token itself; paste the booth's view token in its place.

    overlay.html with no panel shows the same addresses as a card, with the token already in on a machine where the dashboard is set up — which is also what a misconfigured source displays, so an operator finds it in the OBS preview rather than a blank layer.

    every page

    Nothing is hidden: the strip at the top of each page links them all, and a page that takes a token says which one on its own lock.

    • tournament — the schedule in the reader's own time zone and the bracket as far as it is decided. The page to send viewers and creators: it takes no token once the bracket is published.
    • view — the dashboard: the match, the map and the feed, and this service's front page at /. Locked behind the booth's view token.
    • bracket — standings, pairings and the computed final. The same view token.
    • operator — the verbs, who is here and the roster. Locked behind the operator token, because watching must not confer writing.
    • events — the archive: every line the booth's window still holds. The same view token.
